# 海味山东：从渔港到世界餐桌

> 山东大学翻译学院 ·「蓝色创想 · 以语为桥」跨文化传播创新实践大赛  
> 赛道：数字传播 ｜ 形式：交互式网页 ｜ 团队：待填

一个围绕**山东海洋饮食文化**的单页叙事网页：四座渔港、八道海味、六个漂洋过海的词。
核心不是「翻译成四种语言」，而是把翻译本身做成可以点击、翻面、答错的交互。

> **浏览方式：点击翻页**（一屏一页）。点右下角「← →」，或点右侧圆点跳页；键盘 ↑↓ / ←→ / PageUp·PageDown / 空格也可切换，滚轮同样会翻页。手机上可上下轻扫，内容过长的页面在页内滚动。

## 一、怎么打开

**方式一（最稳，评委本地也能看）**：双击 `index.html`，浏览器直接打开。
页面**没有任何外部依赖**（无 CDN、无字体外链、无构建步骤），断网也能正常显示。

**方式二（推荐提交线上链接）**：把整个文件夹传到 GitHub Pages / Vercel / Netlify，得到网址后写进邮件正文。

> 建议 Chrome / Edge / Safari 最新版；Firefox 亦可。手机端已适配。
> 布局按 1440×900 / 1920×1080 设计；在 1366×768 等矮屏上会自动压缩，个别页（如港口档案）可页内滚动。

## 四、内容怎么改（给模块 D / E）

### 1. 界面文案 `js/i18n.js`

```js
window.I18N = {
  zh: { nav_ports: "港口", ... },
  en: { ... }, ja: { ... }, ko: { ... }
};
```

- 四种语言必须保持**同一批 key**，否则切换会显示 fallback 中文。
- 需要改的常用 key：`s1_title`（章节标题）、`s1_lead`（导语）、`map_hint`、`quiz_*`、`about_concept`。

### 2. 内容数据 `js/data.js`

每个字段都是四语对象：

```js
story: {
  zh: "……",
  en: "……",
  ja: "……",
  ko: "……"
}
```

| 字段 | 说明 |
|---|---|
| `cities[].story / forms / note` | 港口故事、四种语言的叫法、跨文化笔记 |
| `cities[].x / y` | 在地图 SVG（760×620）里的坐标，换地图才需要改 |
| `lexicon[].glyph / pinyin / forms / story` | 词源卡片：大字、拼音、多语形式、词源故事 |
| `dishes[].char / names / tag` | 宴席卡片：盘心汉字、四语菜名、标签 |
| `craft[]` | 工序：`verb`（中文动词 + 三语翻译）、标题、说明、小贴士 |
| `quiz[]` | 题目、四个选项、`answer`（正确选项下标，0 起）、解释；**选项顺序运行时随机** |
| `timeline[]` | 年表：年份、朝代标签、标题、正文 |
| `refs[]` | 参考资料（中文，直接显示） |
| `aiStatement[]` | 页面内「AI 创作说明」弹窗内容 |

> 改完之后一定要切到 **EN / 日本語 / 한국어** 各看一遍，检查换行和长短（英文容易撑高卡片）。

### 3. 常见替换

- **团队名称 / 成员**：`js/i18n.js` 里 `about_team`、`about_team2`（四种语言各改一次）。
- **首屏数据**：`index.html` 里 `hero-stats` 的 `4 / 8 / 6 / 4`，和章节数量保持一致。
- **配色**：`css/base.css` 顶部 `:root` 的 `--cinnabar`（朱砂）、`--teal`、`--paper`。

## 五、部署（生成线上链接）

### GitHub Pages（最省事）

1. 新建仓库，上传本文件夹全部文件（`index.html` 在根目录）。
2. Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`。
3. 等 1 分钟，得到 `https://用户名.github.io/仓库名/`。

### Vercel / Netlify

- 直接拖拽文件夹到 Netlify Drop，或 Vercel 导入仓库（Framework 选 Other，Build 留空）。
- 得到 `https://xxx.vercel.app` / `https://xxx.netlify.app`。

> 无论是否部署，压缩包里都要保留源码，并确保 `index.html` 双击可开（本页已满足）。

### 部署后：设置分享卡片（OG）

`index.html` 的 `<head>` 里已经写好 `og:title` / `og:description` / `og:image` / `twitter:card` 等标签，但**社交平台要求图片和网址是绝对地址**，所以部署后要做一步替换：

```powershell
# 在项目根目录执行，把网址换成实际部署地址
powershell -ExecutionPolicy Bypass -File tools/set-site-url.ps1 https://你的域名
```

它会自动把 `__SITE_URL__` 全部替换成 `https://你的域名`。然后：

1. 用 [opengraph.xyz](https://www.opengraph.xyz/) 或微信/QQ 实际分享一次，确认卡片标题、描述、封面都正常。
2. 分享封面在 `preview/og-cover.jpg`（1200×630，≈86 KB），源文件是 `tools/og-cover.html`，要改文案可重新截图生成。
3. 如果平台仍显示旧卡片，是缓存导致，换一个链接参数（如 `?v=2`）或等几分钟再试。

## 八、技术备注

- 纯静态：HTML + CSS + 原生 JS（ES5 语法，兼容性好），无构建、无依赖。
- 翻页实现：`js/deck.js` 用 `transform: translateY()` 做整页上下切换，不依赖滚动条；当前页内容过长时自动改为页内滚动（`is-tall`）。
- 手机端：翻页条放进底部 54px 的独立控制条，正文区域整体上移，永久避免遮挡。
- 答题页：容器固定高度，提交选项时页面重心不移动，不会出现「突然空一下」的跳动。
- 数据与视图分离：`data.js` / `i18n.js` 不参与逻辑，方便非技术同学改稿。
- 地图为手绘简笔 SVG，不涉及行政边界；如需替换真实底图，请使用自然资源部标准地图并保留「示意图」标注。
- 无障碍：语言按钮、翻页按钮、港口节点、词源卡支持键盘操作；`prefers-reduced-motion` 下关闭动画。
- 语言偏好记在 `localStorage`，刷新后保持；文件被禁用存储时自动回退中文。
